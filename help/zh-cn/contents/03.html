2026/08/30 版本 3.5.0

  • 修正 Windows 11 26H1 版本的检测方法。
  • 添加大尺寸图标。
  • 添加安装程序版本。

2026/02/22 版本 3.4.2

  • 修正巴西葡萄牙语翻译。(pt-BR.lng)

2026/02/07 版本 3.4.1

  • 修正启动参数 -force 无效的问题。

2025/04/19 版本 3.4.0

  • 添加 -delay 命令行参数，以应对某些情况下系统开机时会主动更改系统字体的问题，延迟应用设置以覆盖系统更改。
  • 现在 Windows 11 22H2 及更高版本在确认警告后亦可尝试更改标题栏字体，并添加 -force 启动参数（实验性功能）。

2024/02/25 版本 3.3.0

  • 现在可自定义本软件自身的界面字体。

2023/09/03 版本 3.2.1

  • 更新了简体中文（中国）与繁体中文（台湾）翻译。
    感谢 HSSkyBoy 与 kingofotaku。
  • 帮助文档中简体中文表述变更为“简体中文（中国）”。(zh-CN.chm)
    感谢 HSSkyBoy。
  • 帮助文档中繁体中文表述变更为“繁体中文（台湾）”。(zh-TW.chm)
    感谢 HSSkyBoy。

2023/08/27 版本 3.2.0

  • 使软件显示语言跟随 Windows 系统的显示语言设置。
  • 修正了在 Windows 11 记事本等程序中出现边框线条的显示异常。
  • 由于上述修正，将最低支持系统版本调整为 Windows Vista。
  • 导入字体设置时自动根据当前的界面 DPI 调整字体大小。
  • 修正更改标题栏字体大小时导致标题栏过高的问题。

2022/09/26 版本 3.1.0.1

  • 采用 Visual C++ 2008 进行构建以避免杀毒软件误报。

2022/09/21 版本 3.1.0

  • 在 Windows 11 2022 Update(22H2) 中，出于避免在将标题栏设置为透明时产生问题，强制将标题栏字体固定为系统默认字体。
  • 出于上述原因，如今在 Windows 11 22H2 中已无法选择并更改标题栏字体。
  • 在 Windows 11 2022 Update 中使系统版本号得以正确显示。

2022/06/26 版本 3.0.0.1

  • 加入由 Luke Luo 提供的简体中文翻译及字体显示设定。

2022/02/13 版本 3.0.0

  • 现在配置文件中的字体大小以 pt 为单位。
    注意：第 2 版与第 3 版的字体配置文件不可互相替代。
  • 语言资源文件改用 UTF-8 编码。
  • 调整各设置按钮文字使其更易于理解。

2021/11/28 版本 2.42（仅于 GitHub 发布）

  • 添加 Windows 11 默认系统字体支持。
  • 支持 Windows 11 版本号显示。

2021/01/10 版本 2.41

  • 支持读取字体下的所有样式。
  • 支持显示 Windows 10 Version 20H2 版本号。
