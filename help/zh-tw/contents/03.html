3.版本歷程記錄

2026/08/30 版本 3.5.0

  • 修正 Windows 11 26H1 版本的偵測方法。
  • 新增大尺寸圖示。
  • 新增安裝程式版本。

2026/02/22 版本 3.4.2

  • 修正巴西葡萄牙語翻譯。(pt-BR.lng)
  • 修正說明文件。(en, ja-JP, pt-BR)
  • 更新版權年份。

2026/02/07 版本 3.4.1

  • 修正啟動參數 -force 無效的問題。

2025/04/19 版本 3.4.0

  • 新增 -delay 命令列參數，以因應某些情況下系統開機時會主動變更系統字型的問題，延遲套用設定以覆蓋系統變更。
  • 現在 Windows 11 22H2 及更新版本在確認警告後亦可嘗試變更標題列字型，並新增 -force 啟動參數（實驗性功能）。

2024/03/05 版本 3.3.1

  • 更新簡體中文（中國）翻譯。(zh-CN.lng, zh-CN.chm)
    感謝 kingofotaku。
  • 更新繁體中文（台灣）翻譯。(zh-TW.lng)
    感謝 abc0922001。

2024/02/25 版本 3.3.0

  • 現在可自訂本軟體自身的介面字型。
    同時調整了日語環境下的預設字型。
  • 新增禁止重複啟動本軟體的選項。
  • 更新繁體中文（台灣）翻譯。(zh-TW.lng)
    感謝 jay900604。

2023/09/03 版本 3.2.1.1

  • 更新繁體中文（台灣）翻譯。(zh-TW.lng)
    感謝 abc0922001。

2023/09/03 版本 3.2.1

  • 更新了簡體中文（中國）與繁體中文（台灣）翻譯。
    感謝 HSSkyBoy 與 kingofotaku。
  • 說明文件中簡體中文表述變更為「簡體中文（中國）」。(zh-CN.chm)
    感謝 HSSkyBoy。
  • 說明文件中繁體中文表述變更為「繁體中文（台灣）」。(zh-TW.chm)
    感謝 HSSkyBoy。

2023/08/27 版本 3.2.0

  • 使軟體顯示語言依隨 Windows 系統的顯示語言設定。
  • 修正在 Windows 11 記事本等程式中出現邊框線條的顯示異常。
  • 由於上述修正，將最低支援系統版本調整為 Windows Vista。
  • 匯入字型設定時自動依據目前的介面 DPI 調整字型大小。
  • 修正變更標題列字型大小時導致標題列過高的問題。

2022/09/26 版本 3.1.0.1

  • 使用 Visual C++ 2008 進行建置以避免防毒軟體誤判。

2022/09/21 版本 3.1.0

  • 在 Windows 11 2022 Update(22H2) 中，為避免標題列透明化時發生問題，強制將標題列字型固定為系統預設字型。
  • 因上述原因，在 Windows 11 22H2 中暫時停用標題列字型變更功能。
  • 修正 Windows 11 2022 Update 的系統版本號顯示。

2022/06/26 版本 3.0.0.1

  • 加入由 Luke Luo 提供的簡體中文翻譯及字型顯示設定。

2022/02/13 版本 3.0.0

  • 設定檔中的字型大小改以 pt 為單位。
    注意：第 2 版與第 3 版的字型設定檔無法通用。
  • 語言資源檔案改採 UTF-8 編碼。
  • 調整各按鈕文字使其更容易理解。

2021/11/28 版本 2.42（僅於 GitHub 發布）

  • 加入 Windows 11 預設系統字型支援。
  • 支援 Windows 11 版本號顯示。

2021/01/10 版本 2.41

  • 支援讀取字型下的所有樣式。
  • 支援顯示 Windows 10 Version 20H2 版本號。

2020/07/26 版本 2.40.2

2020/06/28 版本 2.40.1

2020/05/31 版本 2.40

  • 新增「套用」按鈕，按下後可套用設定且不關閉程式。
  • 主介面分為「全部字型設定」與「個別字型設定」兩組。
  • 修正在特定情況下無法讀取目前目錄設定檔的問題。

2020/01/13 版本 2.36

  • 點選設定全部字型後自動結束程式。
  • 新增葡萄牙語（巴西）翻譯。
  • 新增繁體中文翻譯。
  • 包含 2.35 中遺漏的簡體中文翻譯。

2018/04/28 版本 2.35

  • 當 Windows 顯示語言與地區設定不同時，優先以顯示語言決定軟體介面語言。
  • 加大軟體各處的字型大小。
  • 新增韓文翻譯（感謝 deVbug 協助）。
  • 支援韓文字型名稱替代。
  • 改進簡體中文翻譯（感謝 kingofotaku 協助）。

2017/06/03 版本 2.34

  • 主視窗啟動時置中顯示於螢幕。
  • 字型選取對話方塊顯示於主視窗上方。
  • 修正說明文件中的字型問題。

2017/05/14 版本 2.33

  • 在 Windows 10 上可顯示詳細版本資訊。
  • 重設系統預設字型功能支援英文版。
  • 語言檔案中加入預設字型與字元集。
  • 支援依據系統語言自動選擇對應語言與說明文件。

2016/10/10 版本 2.32

  • 新增簡體中文說明文件（感謝 立花 月下 協助）。
  • 重設系統預設字型功能支援簡體中文。

2016/09/19 版本 2.31

  • 新增簡體中文介面翻譯。
  • 說明文件改為 HTML 格式。
  • 版本資訊中加入翻譯者名單。

2016/08/19 版本 2.30

  • 在非日文系統上執行時可根據系統語言切換介面語言。本版本新增了對日文、簡體中文（中國）及其他語言的切換支援。
    （因作者當時不熟悉中文，故本版本在簡體中文 Windows 上暫以英文顯示作為過渡。）

2016/06/09 版本 2.20

  • 支援透過命令列讀取指定的字型設定檔，並支援直接將系統字型套用為命令列指定設定檔中的內容。

2016/02/23 版本 2.17

  • 所選字型的字型名稱與大小將直接以該字型本身的字形樣式進行預覽顯示。
    （不過單看字型名稱的話，Meiryo UI 看起來還挺像個正常的字型，倒成了唯一的難點。）
