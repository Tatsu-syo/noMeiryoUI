1.快速入門

1.1 這是什麼軟體？

　本軟體是用於在 Windows 8/8.1/10/11 上自訂系統各部分字型的工具。
　由於 Windows 自 8/8.1/10 起取消了直接自訂系統介面字型的功能，因此開發了本軟體。

1.2 運作環境

　本程式可在 Windows 8/8.1/10/11 上運作。
　本軟體為桌面應用程式，用於設定桌面上顯示之視窗各部分的字型。

　雖然也能在 Windows Vista、7 上運作，但這些系統本身即可直接設定各部分字型，因此無此必要。

1.4 安裝與解除安裝

安裝

　使用可攜版時，請將本軟體的壓縮檔解壓縮至同一資料夾中即可。

解除安裝

　若要解除安裝可攜版，直接刪除本軟體所在的整個資料夾即可。

1.5 疑難排解

變更字型前的登錄檔備份

　在執行本程式變更字型前，建議先執行 utils\SAVEreg.bat 備份字型相關的登錄檔（需要系統管理員權限）。
　備份檔案將儲存於 C:\Users\(使用者名稱)\AppData\Local 目錄下。

發生問題時的處理方式

　若在套用設定後發生問題，且先前已透過 utils\SAVEreg.bat 建立備份，可執行 utils\RESTOREreg.bat 還原回原先的狀態（需要系統管理員權限）。
