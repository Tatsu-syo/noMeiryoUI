2.如何使用本軟體

2.1 簡介

　在檔案總管中按兩下 noMeiryoUI.exe 的圖示 即可啟動軟體。
　啟動後將會顯示如下介面。
　目前的 Windows 版本資訊將以系統名稱（組建號碼）顯示在主介面上方。若您需要向作者回報問題或錯誤，可一併附上此資訊。


2.2 操作方法

　主介面顯示後，目前的系統各部分所使用的字型名稱也會一併列出。

一併設定所有系統字型

 上方「全部字型設定」群組可用於將選定的字型一次套用至下方所有系統介面項目。

 「全部字型」右側的文字方塊中顯示目前選取的字型。
 按下該欄右側的「選取」按鈕後，即可從彈出的字型選取對話方塊中選擇字型。
 點選「套用全部並結束」即可將所有系統介面字型、大小與樣式一併變更並關閉程式。
 點選「套用」則會在套用變更後繼續保留程式視窗。

個別設定各介面項目的字型

 下方「個別字型設定」群組可用於對系統介面的各個項目單獨指定字型。

　若要變更特定項目之字型，請點選該項目右側的「選取」按鈕。
　在彈出的字型選取對話方塊中選擇您偏好的字型、大小與樣式。

　設定完成後，點選「套用並結束」可將字型套用至系統並關閉程式。
　點選「套用」可套用至系統而不關閉程式。
　點選「結束而不套用」可直接結束程式。

2.3 選取字型

　按下「選取」按鈕後，軟體將會彈出如下的字型選取對話方塊：


　透過字型選取對話方塊可進行下列設定：

名稱功能
字型名稱(F)選取字型。
字型樣式(Y)指定字型的字形樣式。
大小(S)指定字型大小（pt）。
粗體(B)勾選此項目以粗體顯示。
斜體(I)勾選此項目以斜體顯示。
底線(U)勾選此項目以加上底線。
刪除線(T)勾選此項目以加上刪除線。
字元集(C)選取字型的字元集編碼。

　選取完畢後按一下「確定」按鈕即可套用該字型設定。
　若有未選取的必要項目，軟體將會顯示警告，屆時請依提示操作。

2.4 選單操作

  • 檔案(F)
    • 載入字型設定檔(O)...
      載入先前儲存的 ini 字型設定檔。選擇此項目後將開啟檔案選取對話方塊。
      載入後，軟體內從「標題列」到「選單」各項目的字型將會更新為設定檔中的內容，接著可點選「套用」或「套用並結束」使其生效。
    • 儲存字型設定檔(A)...
      將目前的字型設定儲存為 ini 設定檔。
      將會儲存從「標題列」到「選單」各項目的設定內容。
      點選後將彈出儲存檔案對話方塊，輸入檔名後即可儲存。
    • 設定系統字型並退出(S)
      套用所有系統字型設定後關閉程式。
    • 結束(X)
      不套用任何變更直接結束程式。
  • 重設為預設設定(P)
    • Windows 8/8.1
      將個別設定中的字型重設為 Windows 8/8.1 的預設字型。
    • Windows 10
      將個別設定中的字型重設為 Windows 10 的預設字型。
    • Windows 11
      將個別設定中的字型重設為 Windows 11 的預設字型。
  • 工具(T)
    • 選擇 No!! Meiryo UI 應用程式字型(F)
      自訂本軟體介面自身所使用的顯示字型。
    • 在另一執行緒中變更字型(A)
      特殊環境下用於排除無回應等問題的選項。
      若在背景執行特定鍵盤滑鼠驅動程式（如 SetPoint）時發生字型設定卡住或無回應的情況，可勾選此選項後再進行設定。
    • 將字型大小視為與 Windows 7 相同(7)
      在 Windows 8/8.1 上將字型大小的計算方式切換為與 Windows 7 相同。
    • 不要重複執行(D)
      啟用此選項可防止重複開啟多個本軟體視窗。
    • 允許變更標題列字型(O) （實驗性功能）
      在 Windows 11 22H2 及更新版本中，微軟限制了標題列字型的變更。啟用此選項可強制開啟標題列字型的設定按鈕。
      注意：在 Windows 11 22H2 及更新版本中強制變更標題列字型可能會引發未知問題或介面異常，因此本功能不提供任何擔保。
  • 說明(H)
    • 檢視說明(C)
      開啟本說明文件。
    • 關於 No!! Meiryo UI (A)
      顯示軟體版本與相關資訊。

2.5 命令列選項

　透過命令列參數，可在啟動時自動載入指定的設定檔，或直接在背景套用字型設定。

　命令列格式如下：
noMeiryoUI [字型設定檔路徑] [選項...]

　若檔案名稱或路徑中包含空格，請使用半形雙引號 "" 包裹。
　使用多個選項時請以半形空格分隔。

選項

在 [選項...] 中可使用下列參數：

  • -set
    　-set 選項可在啟動時直接套用指定的字型設定檔並立即結束程式。
    非常適合用於 Windows 啟動捷徑、開機啟動項目或批次檔中。
  • -delay
    　-delay 選項可以指定延遲套用字型設定的秒數（例如：-delay 60）。
    若系統在開機登入後會自動覆蓋字型，可使用此選項在系統重設字型之後再重新套用設定。
  • -force（實驗性）
    　-force 選項可在 Windows 11 22H2 及更新版本中強制變更標題列字型。
    在 Windows 11 22H2 及更新版本中變更標題列字型可能會引發未知問題，本選項不作任何保證。

範例 1：啟動軟體時自動載入 MySet.ini 設定檔

noMeiryoUI MySet.ini

範例 2：直接套用 Your Settings.ini 的設定並結束程式

noMeiryoUI "Your Settings.ini" -set

範例 3：延遲 60 秒後套用 restore Settings.ini 的設定並結束程式

noMeiryoUI "restore Settings.ini" -set -delay 60
